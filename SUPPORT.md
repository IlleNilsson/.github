# Xmip Support

Use the issue tracker in the repository that owns the affected capability or component.

If the correct repository is unclear, open an issue in [IlleNilsson/Xmip](https://github.com/IlleNilsson/Xmip/issues) and describe the requirement, affected behaviour and available evidence.

Do not disclose vulnerabilities, credentials, secrets, private keys or personal data in a public issue. Follow the [Xmip security policy](SECURITY.md) instead.
